# عالم الحركة — Body in Motion

Open `index.html` in any browser (double-click). No internet, server, or install needed.

- `index.html` — game engine + UI
- `content.js` — curriculum (Chapter 1: الدعامة والحركة, textbook pp. 33–99). Add missions here.
- `visuals.js` — all interactive SVG diagrams (spine, vertebra, ribs, knee, joint, forearm, pelvis, muscle zoom, sarcomere, neuromuscular junction, graphs)
- `assets/images/` — two public-domain skeleton drawings (Wikimedia Commons)
- `assets/sources/image-sources.json` — license/attribution record (also shown in-game under ⚙️)
- `assets/fonts/` — local copies of the fonts (SIL Open Font License)

Progress is saved in the browser's localStorage on this computer.
